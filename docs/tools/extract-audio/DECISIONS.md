# Extract Audio Architecture Decision Log

## Approved Decisions

### Decision 1: Extract Audio is the next QAVELIX tool

Status: Approved

Reason: Extract Audio offers high reuse of the current video pipeline, low infrastructure risk, fast development, and strong potential for early monetization.

### Decision 2: Extract Audio remains inside the main QAVELIX repository and brand

Status: Approved

Reason: Keeping the tool in the main repository and brand preserves architectural consistency, simplifies maintenance, and supports a unified QAVELIX media-tool ecosystem.

### Decision 3: A centralized Tools menu is planned but not implemented during this documentation task

Status: Approved

Reason: A centralized Tools menu will likely be needed as QAVELIX expands, but this task is limited to documentation structure and must not modify UI, routing, or application behavior.
