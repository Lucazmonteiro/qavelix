# Extract Audio

Extract Audio is a planned QAVELIX tool for extracting audio from uploaded video files.

The tool belongs to the QAVELIX Video and Audio ecosystem. It is intended to extend the current media workflow with a lightweight, useful operation that can reuse parts of the existing video pipeline.

Implementation has not started yet. This folder is only for planning, product definition, architecture notes, SEO preparation, testing strategy, and decision tracking.

## Documentation

- `PRD.md`: product requirements template.
- `ROADMAP.md`: phased delivery plan.
- `TODO.md`: prioritized planning checklist.
- `SEO.md`: search and metadata planning template.
- `TESTS.md`: test planning outline.
- `DECISIONS.md`: architecture and product decision log.
